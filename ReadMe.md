# BetterScreenShot

Screenshot mode for Hollow Knight. Press **PrintScreen** (**Cmd+Shift+2** on macOS) in game: the game freezes,
the cursor appears, and you can zoom out, select an area and save it.

## Controls

| Action | Key |
|---|---|
| Open / close the mode | PrintScreen, Esc |
| Zoom (up to ×25) | slider, mouse wheel, `+` / `-` |
| Move the camera | right/middle mouse drag, arrows / WASD |
| Select an area | two clicks or drag |
| Clear the selection | Backspace, right click |
| Select the whole screen | Ctrl+A |
| Copy to clipboard | Ctrl+C |
| Save as… | Ctrl+S |
| Pause / play | Space |
| Step 1 / 10 frames | `.` / Shift+`.` |
| Save diagnostics | F9 |

On macOS use Cmd instead of Ctrl.

## Options

- **Native resolution**: the area is rendered at normal-zoom detail, however far the camera is zoomed out
  (at ×3, a 600×400 area gives a 1800×1200 image).
- **Remove the vignette and visual masks**: on by default.

The HUD and the mod's panels never end up in the picture.
